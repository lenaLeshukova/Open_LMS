# Open LMS - Платформа для онлайн-обучения 

Служебный проект SPA веб-приложения (LMS-системы), разработанный на Django REST Framework. Позволяет пользователям размещать свои полезные курсы и учебные материалы, а также отслеживать историю платежей. Бэкенд-сервер общается с клиентом посредством JSON-структур. Приложение полностью защищено авторизацией на базе JWT-токенов и реализует разграничение прав доступа.


## 🛠 Стек технологий
* **Python** 3.12
* **Django** 5.2+ (с поддержкой конфигурации `MAILERS`)
* **Django REST Framework** (DRF)
* **Poetry** (управление зависимостей)
* **PostgreSQL** & **Psycopg (Binary)** (база данных)
* **Pillow** (работа с изображениями и аватарами)
* **Python-dotenv** (изоляция секретных переменных окружения)

## 🔐 Матрица прав доступа (Валидация по критериям)

Проект реализует жесткое разграничение прав доступа на уровне объектов (**Object-level permissions**) и глобальных настроек проекта:
1. **Анонимный пользователь**: имеет доступ исключительно к регистрации (`/api/users/register/`) и получению токенов (`/api/token/`). Все остальные эндпоинты закрыты на уровне проекта (`DEFAULT_PERMISSION_CLASSES`).
2. **Обычный пользователь (Владелец)**: 
   * Может создавать курсы и уроки. При создании владельцем автоматически назначается текущий авторизованный пользователь (`perform_create`).
   * Может просматривать, редактировать и удалять **только свои** курсы и уроки. В списках (`get_queryset`) чужие записи скрыты.
3. **Модератор** (пользователь, состоящий в группе `модераторы`):
   * Может просматривать и редактировать **любые** курсы и уроки в системе.
   * **Не имеет прав** на создание (`create`) или удаление (`destroy`) любых курсов и уроков.

## 🚀 Инструкция по локальному развертыванию

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd Open_LMS
```

### 2. Настройка виртуального окружения через Poetry
Убедитесь, что у вас установлен Poetry. Установите все зависимости проекта:
```bash
poetry install
poetry shell
```

### 3. Настройка переменных окружения
Создайте в корне проекта файл `.env` и заполните его своими данными:
```env
# Django настройки
SECRET_KEY=your_django_secret_key
DEBUG=True

# Настройки базы данных PostgreSQL
DB_NAME=open_lms
DB_USER=postgres
DB_PASSWORD=your_postgres_password
DB_HOST=127.0.0.1
DB_PORT=5432

# Настройки почты Яндекс SMTP
EMAIL_PASSWORD=your_yandex_app_password
```

### 4. Подготовка базы данных и миграции
Перед первым запуском убедитесь, что в вашей СУБД PostgreSQL создана пустая база данных `open_lms`. Затем последовательно примените миграции и загрузите тестовые данные платежей:
```bash
python manage.py makemigrations
python manage.py migrate
python manage.py loaddata users/fixtures/payments_data.json
python manage.py loaddata users/fixtures/payments_data.json
```

### 5. Запуск сервера разработки
```bash
python manage.py runserver
```
Сервер будет доступен по локальному адресу: `http://127.0.0.1:8000/`

## 📡 Эндпоинты API (Примеры для тестирования в Postman)

Для выполнения запросов, требующих авторизации, необходимо передавать токен на вкладке **Authorization** -> **Bearer Token**.

### 🔐 Авторизация и пользователи (Доступно без токена)
* `POST` `/api/users/register/` - Регистрация нового пользователя.
* `POST` `/api/token/` - Получение пары access/refresh токенов (Логин). В Body передавать `email` и `password`.
* `POST` `/api/token/refresh/` - Обновление access-токена.

### 👤 CRUD Пользователей (Требуется токен)
* `GET` `/api/users/` - Список пользователей.
* `GET` `/api/users/<id>/` - Детали пользователя.
* `PUT` `/api/users/update/<id>/` - Редактировать профиль.
* `DELETE` `/api/users/delete/<id>/` - Удалить пользователя.

### 📚 Курсы (Реализовано через ViewSets. Разделение прав по action)
* `GET` `/api/courses/` - Получить список курсов (Владелец видит свои, модератор - все). Возвращает массив уроков `lessons` и динамическое поле `lessons_count`.
* `POST` `/api/courses/` - Создать новый курс (**запрещено модераторам**).
* `GET` `/api/courses/<id>/` - Детали курса (Доступно владельцу или модератору).
* `PUT` `/api/courses/<id>/` - Обновить курс (Доступно владельцу или модератору).
* `DELETE` `/api/courses/<id>/` - Удалить курс (**доступно только владельцу**, модераторам запрещено).

### 📝 Уроки (Реализовано через Generics. Разделение прав через permission_classes)
* `GET` `/api/lessons/` - Список уроков (Владелец видит свои, модератор - все).
* `POST` `/api/lessons/create/` - Создать урок (**запрещено модераторам**).
* `GET` `/api/lessons/<id>/` - Детали урока (Доступно владельцу или модератору).
* `PUT` `/api/lessons/update/<id>/` - Редактировать урок (Доступно владельцу или модератору).
* `DELETE` `/api/lessons/delete/<id>/` - Удалить урок (**доступно только владельцу**).

### 💳 Платежи (Сортировка и фильтрация)
* `GET` `/api/payments/` - Список всех платежей.
  * *Фильтр по курсу:* `/api/payments/?paid_course=<id>`
  * *Фильтр по уроку:* `/api/payments/?paid_lesson=<id>`
  * *Сортировка по дате (от новых к старым):* `/api/payments/?ordering=-payment_date

*Пример комбинированного запроса:* `/api/payments/?paid_course=1&ordering=-payment_date`
